What is the Gmail dot trick?

The Gmail dot trick is adding dots to the username part of a Gmail address (everything before the @) to get addresses that look different but deliver to the same inbox. Google confirms that dots don’t matter in @gmail.com addresses, so every dotted version below belongs to the owner of johnsmith@gmail.com.

How many dot variations does a Gmail address have?

A username with n characters has 2n−1 dot placements, because each gap between two characters can hold a dot or not. The count doubles with every extra character:

What marketers use Gmail dot variations for

  • Test complete email automations. Run welcome series, abandoned-cart and post-purchase flows with a different address each time, all landing in one inbox.
  • Validate forms and segmentation. Submit each variation through forms and pop-ups to confirm tags, list routing and personalization.
